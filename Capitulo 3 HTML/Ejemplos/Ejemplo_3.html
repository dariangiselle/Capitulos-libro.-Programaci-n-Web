Java How to Program, 9/e

De Java How to Program, 9/3

Características:

  • Extensa cobertura de los fundamentos: dos capítulos sobre instrucciones de control.
  • Enfoque en ejemplos del mundo real.
  • Conjunto de ejercicos para Hacer la diferencia.
  • Introducción desde los primeros capítulos a las clases, objetos, métodos y cadenas.
  • Manejo de excepciones integrado.
  • Archivos, fluos y serialización de objetos.
  • Secciones modulares opcionales sobre el lenguajje y características de la biblioteca de la nueva versión Java SE 7.
  • Otros temas: Recursividad, búsqueda, ordenamiento. colecciones genéricos, estructuras de datos, applets, multimedia, multihilos, bases de datos/JDBC™, desarrollo de aplicaciones web, servicios web y un caso de estudio opcional de Diseño orientado a objetos con un ATM.
