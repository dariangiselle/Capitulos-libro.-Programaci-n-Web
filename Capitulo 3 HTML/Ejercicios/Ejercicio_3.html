Ejercicio

3.3 Complete las siguientes oraciones:

Las respuestas estan con negritas

a. El atributo autofocus (que se utiliza en un solo elemento input en un formulario) resalta de manera automática el elemento imput y, si se usa de manera apropiada, coloca el cursor en el campo de texto de que el navegador carga y despliega la página.


b. Los nuevos tipos input de HTML5 tienen validación del lado del cliente.


c. El tipo input number permite al usuario introducir un valor numérico.


d. El tipo input range se valida automáticamente de manera intrínseca cuando lo despliega el navegador como un control deslizante, ya que el usuario no puede mover el control fuera de los límites del valor mínimo o máximo.


e. El atributo autocomplete puede usarse en los tipos input para completar de manera automática la información del usuario con base en datos de entrada anteriores.


f. El elemento figcaption proporciona una leyenda para la imagen en el elemento figure.


g. El elemento summary muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento details.


h. El elemento mark nos permite resaltar texto.
