Ejercicio

3.4 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

a. Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color.

Falso. Se necesita que el usuario ponga un valor hexadecimal de 6 dígitos (como #FF0000), no el nombre del color en texto.


b. Cuando un usuario introduce datos en un formulario y luego lo envía (por lo general, al hacer clic en el botón Enviar), el navegador verifica de inmediato que los datos sean correctos.

Verdadero.


c. HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad.

Falso. HTML5 sólo valida la sintaxis y el formato de la dirección (que contenga un formato como usuario@dominio), pero no verifica si la cuenta existe en el servidor.


d. Puede agregar required a cualquiera de los tipos input.

Verdadero.


e. Puede habilitar autocomplete sólo para ciertos elementos input.

Verdadero.


f. El elemento time nos permite identificar una fecha, hora o ambas.

Verdadero.


g. El elemento caption proporciona una leyenda para la imagen en un elemento figure.

Falso. El elemento que proporciona una leyenda para figure es figcaption. El elemento caption se utiliza para poner leyenda a una tabla (table).


h. El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento summary.

Falso. Es el elemento summary el que muestra la leyenda/flecha, y al hacer clic en él se revela el contenido del elemento details (el funcionamiento está invertido en la afirmación).


i. El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section.

Verdadero.


j. El elemento highlight nos permite resaltar texto.

Falso. El elemento correcto para resaltar texto en HTML5 es mark. El elemento highlight no existe en HTML.
