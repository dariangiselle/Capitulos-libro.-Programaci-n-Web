Ejercicio de Autoevaluación

3.2 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso explique por qué.

a. Cualquier tipo de imput particular de formulario de HTML5 debe desplegarse de manera idéntica en todos los navegadores compatibles con HTML5.

Falso. Porque varía según el navegador desde el que se acceda.


b. Cuando se coloca el enfoque en el campo de texto (es decir, si el cursor está en el campo de texto), se envía el texto del atributo placeholder al servidor.

Falso. Si el cursor está en el campo de texto, placeholder desaparece y no se envía el texto solo si el usuario da clic en enviar.


c. No es necesario incluir el atributo autofocus en sus formularios.

Verdadero.


d. Los nuevos tipos imput de HTML5 tienen validación automática del lado del cliente, con lo cual se elimina la necesidad de agregar secuencias de comandos (script) complicadas a sus formularios para validar la entrada del usuario y se reduce la cantidad de datos inválidos que se envían.

Verdadero.


e. El tipo imput range se valida automáticamente de manera intrínseca cuando el navegador lo despliega como un control deslizante, ya que el usuario no puede mover el control fuera de los límites del valor mínimo o máximo.

Verdadero.


f. HTML5 cuenta con validación automática para el tipo input tel.

Falso. La longitud y el formato de los números telefónicos varícon base en la ubicación y la validación se vuelve completa, HTML5 no cuenta con validación automática con input tel.


g. Si el usuario introduce un URL con un formato inapropiado en un tipo input url, no se validará. HTML5 no valida si el URL introducido existe en realidad.

Verdadero.


h. El elemento nav muestra un menú desplegable de hipervínculos.

Falso. nav agrupa vínculos de navegación.


i. El elemento header puede usarse sólo una vez en una página

Falso. header puede usarse varias veces en una página e incluye encabezados de HTML.


j. Los elementos nav pueden anidarse en un elemento aside

Verdadero.


k. Podemos usar el elemento brk para evitar dividir palabras en lugares incorrectos.

Falso. Para evitar dividir las palabras en lugares incorrectos se usa wbr
